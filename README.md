# 🎵 Spotify Clone (HTML & CSS)

This is a simple **Spotify Web UI Clone** built using **HTML and CSS**.
It replicates the basic look and feel of Spotify's homepage.

---

## 🚀 Features

* 🎧 Modern Spotify-inspired UI
* 📱 Basic responsive design
* 🎨 Clean and structured layout
* 🖼️ Album & playlist sections

---

## 🛠️ Technologies Used

* HTML5
* CSS3
